# 생활비서 자연유입 확장 및 자동운영 계획 (2026-11-05)

## 목표
생활비서를 자동차·지원정책 중심 정보 사이트에서 '돈·집·일·생활 문제를 해결하는 사이트'로 확장한다.
검색 결과로 들어온 사람이 계산·비교·공식 민원처리 등을 끝낼 수 있는 고유 가치를 제공한다.
일일 글 발행량이나 키워드 수가 아니라 검색 유입, 해결 완료와 재방문을 성장 지표로 둔다.

## 확장 체계
automation/growth-taxonomy.json에서 20개 주제군의 검색어·콘텐츠 각도를 관리한다.
상위 묶음은 돈(세금·환급, 대출·신용, 카드·은행, 연금, 개인사업자),
집(부동산·전월세, 이사·주거관리, 공과금),
일(근로·퇴직, 재취업·자격증, 교육비),
가족(복지, 의료비, 육아),
소비(자동차, 통신, 쇼핑, 교통·여행),
민원(행정, 생활법률)로 구성한다.
현재 실제 게시 구조는 자동차와 지원정책 2개 카테고리뿐이다.
20개를 빈 인덱스 페이지로 즉시 만들지 말고 양질의 글이 모인 순서대로 메뉴를 확장한다.
기존에 색인된 글의 canonical URL은 유지한다.

## 콘텐츠 단위
하나의 분야에 대표 글, 개인 상황별 질문형 글, 계산·비교 도구, 실제 행정 절차, 갱신 공지의 다섯 유형을 연결한다.
우선 실험 묶음은 연말정산과 월세 공제, 프리랜서 세금, 주택대출 DSR, 전세보증금,
실업급여·퇴직금, 전기·관리비 계산을 선정한다.

## 자동화 상태
discovered → demand_checked → source_verified → draft_ready → editorial_review → approved → published → recheck_due

현재 구현: 공식 RSS에서 매일 신규 후보 탐색, 20개 분야 자동 분류, 기존 글과 검색 질문 중복 감지,
마지막 확인일이 21일 이상 지난 글 재검토 요청, 결과를 하나의 GitHub 이슈와 Actions artifact에 기록.
GitHub Actions 예약 시각은 한국시간 매일 오전 7시 15분이다.

공식 피드: 금융위원회 보도자료, KOSIS 최근 수록자료, KOSIS 월간동향.
2026년 7월 1일 RSS 서비스 종료를 공지한 정책브리핑 RSS를 사용하지 않는다.
각 출처가 응답하지 않으면 성공으로 처리하지 않고 오류를 보고한다.

아직 미구현: Search Console 실제 검색량 데이터 연동, AI 초안 자동 작성, 편집 승인 후 PR 발행.
출처 수집이 성공해도 기사 내용이 검증됐거나 글이 배포된 것으로 표기하지 않는다.

## 편집 승인 기준
공식 상세 문서 2개 이상, 대상·금액·기간·시행상태 검증, 기존 게시글과 같은 검색의도 차단.
원문 재서술이 아닌 계산·비교·체크리스트·공식절차 등 고유한 추가 가치를 요구한다.
보험 관련 콘텐츠 금지, 정부기관 사칭 금지, AI 직접 경험 및 전문가 자격 날조 금지.
금융·세무·법률 등 높은 위험의 내용은 사람 승인 전 자동 공개 금지.
개정 사실 없이 본문 날짜만 새것으로 바꾸지 않는다.
콘텐츠 수와 AI 생성 속도를 품질 기준으로 삼지 않는다.
